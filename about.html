About Me

Hi, I'm Md. Sujon Uddin, a Web Developer from Bangladesh. I’m passionate about learning web development and creating websites that are clean, responsive, and easy to use. I started my journey with HTML and CSS, and gradually moved into JavaScript and Bootstrap as I wanted to build more interactive and practical websites.

I enjoy learning by working on real projects rather than only focusing on theory. Every project gives me a chance to learn something new, solve problems, and improve the way I write and structure my code. Along the way, I’ve become interested in both the creative and technical sides of web development.

At the moment, I’m expanding my skills with PHP, Laravel, React, and other modern web technologies. I’m still learning and improving every day, but I enjoy the process and the challenges that come with it. My goal is to become a skilled professional Web Developer, work on meaningful projects, and eventually work with clients and companies from around the world.
